# АСУ «Путёвка»

Путевые листы легкового автомобиля по типовой межотраслевой форме № 3 (ОКУД 0345001): расчёт за месяц, печать, учёт топлива, документов, сроков и штрафов.

[![Последний выпуск](https://img.shields.io/github/v/release/MaksimTMB/putevka-rps?label=выпуск)](https://github.com/MaksimTMB/putevka-rps/releases/latest)

Работает на одном компьютере с Windows или на своём сервере с Linux, тогда с ней работают из браузера с нескольких компьютеров. Данные хранятся только у вас.

## Что умеет

- **Путевые листы по форме № 3** за весь месяц: дни, маршруты, время в пути, пробег, расход и остаток топлива по сезонным нормам. Предпросмотр листа А4 в натуральную величину, двусторонняя печать, выгрузка в Word и Excel.
- **Чеки ГСМ.** Ведомости АЗС загружаются файлом; заправки ложатся в путевые листы без переливов бака и отрицательных остатков.
- **Документы.** Загружайте любые файлы: программа сама определяет, что это (ведомость, путевой лист, документ водителя или машины), чей он и за какой месяц, и раскладывает по папкам.
- **Водители и машины.** Карточка водителя с удостоверением: поля читаются с фото, подойдёт снимок телефоном. Госномер, СТС, сроки ОСАГО, техосмотра и медсправки.
- **Сроки и штрафы.** Напоминания об окончании документов в программе, на почту или в Telegram; реестр штрафов по машинам.
- **Пользователи и роли.** Администратор ведёт всё, водитель открывает и печатает свои путевые листы. Вход по паролю, восстановление пароля по коду или письмом.
- **Резервная копия** всей базы одним файлом: выгрузить, перенести на другой компьютер, загрузить обратно.
- **Обновление кнопкой.** Программа сама узнаёт о новой версии; база при обновлении сохраняется.

Фото удостоверения распознаётся прямо в браузере и никуда не отправляется.

## Установка на Windows

Для работы на одном компьютере. Нужна Windows 10 или 11.

1. Скачайте **Putevka.exe** со страницы [последнего выпуска](https://github.com/MaksimTMB/putevka-rps/releases/latest).
2. Запустите его. Программа сама установится в `%LOCALAPPDATA%\Programs\Putevka` (права администратора не нужны) и создаст ярлык «Путёвка» на рабочем столе и в меню «Пуск».
3. При первом запуске создайте администратора и сохраните код восстановления, который покажет программа.

Если Windows предупредит о неизвестном издателе, нажмите «Подробнее» → «Выполнить в любом случае».

База лежит в `%LOCALAPPDATA%\Programs\Putevka\data`.

## Установка на сервер Linux

Для работы с нескольких компьютеров: программа ставится на сервер, а пользователи открывают её в браузере.

```bash
curl -fsSL https://raw.githubusercontent.com/MaksimTMB/putevka-rps/main/install.sh | sudo bash
```

Установщик сам поставит Python (если его нет), скачает последний выпуск, создаст служебного пользователя `putevka` и службу `putevka`, запустит её и проверит, что сервер отвечает. В конце он покажет адрес, например `http://192.168.1.10:8080`.

**Сразу откройте этот адрес и создайте администратора.** Пока администратора нет, первую настройку может пройти любой, кто откроет страницу.

Нужно: Linux с systemd (Ubuntu, Debian, Astra Linux, ALT, РЕД ОС, Rocky, AlmaLinux и др.), около 200 МБ на диске, доступ в интернет к github.com и pypi.org на время установки.

### Ключи

Ключи пишутся после `bash -s --`:

```bash
curl -fsSL https://raw.githubusercontent.com/MaksimTMB/putevka-rps/main/install.sh | sudo bash -s -- --port 8090
```

| Ключ | Что делает |
| --- | --- |
| `--port N` | Порт, по умолчанию 8080. Занятый порт установщик не тронет и попросит выбрать другой. |
| `--dir ПАПКА` | Папка программы, по умолчанию `/opt/putevka`. |
| `--version vX.Y.Z` | Поставить определённую версию, а не последнюю. |
| `--source ПУТЬ` | Поставить из скачанного архива исходников (`.tar.gz`) или папки, без GitHub. |
| `--no-firewall` | Не открывать порт в ufw / firewalld. |
| `--uninstall` | Удалить службу и программу. База и документы остаются в папке `data`. |
| `--uninstall --purge` | Удалить всё, включая данные. Последняя копия данных кладётся в `/var/backups/putevka`. |

### Где что лежит

| Что | Где |
| --- | --- |
| Программа | `/opt/putevka` |
| База и документы | `/opt/putevka/data` |
| Копии перед обновлениями | `/var/backups/putevka` |
| Настройки HTTPS | `/etc/putevka.env` |
| Журнал | `journalctl -u putevka -f` |
| Состояние, перезапуск | `systemctl status putevka`, `systemctl restart putevka` |

### Доступ из интернета

Программа рассчитана на внутреннюю сеть. Если её нужно открыть снаружи, поставьте перед ней обратный прокси с HTTPS (Nginx, Caddy, Nginx Proxy Manager) и ограничьте доступ по адресам. HTTPS можно включить и в самой программе: укажите сертификат и ключ в `/etc/putevka.env` и выполните `systemctl restart putevka`.

### Если установлена старая версия

Сервер, поставленный прежним скриптом `setup_and_run.sh` (папка `/opt/asu_waybills`, служба `putevka`), обновляется той же командой. Установщик найдёт его, сохранит базу и папку, переведёт службу на отдельного пользователя и поправит права на данные.

## Обновление

- **Кнопкой в программе.** Когда выходит новая версия, внизу меню слева появляется «Обновление vX». Нажмите её: программа скачает новую версию и перезапустится, база сохранится.
- **На сервере Linux** можно также повторить команду установки. Перед заменой файлов установщик делает копию программы и данных в `/var/backups/putevka`. Если новая версия не запустится, он сам вернёт прежнюю.

Что изменилось в каждой версии — в [CHANGELOG.md](CHANGELOG.md) и на странице [выпусков](https://github.com/MaksimTMB/putevka-rps/releases).

## Резервные копии

«Документы» → «Резервная копия базы»:

- «Выгрузить всю базу» сохраняет водителей, путевые листы, чеки, штрафы, пользователей и все документы одним файлом;
- «Загрузить базу из файла» переносит базу из такого файла, например на новый компьютер или сервер.

Храните копию отдельно от компьютера с программой.

## Для разработчиков

Запуск из исходников (Python 3.8+):

```bash
git clone https://github.com/MaksimTMB/putevka-rps.git && cd putevka-rps
python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python server.py      # http://127.0.0.1:8080
```

Адрес и порт задаются переменными `PUTEVKA_HOST` и `PUTEVKA_PORT`, HTTPS — `PUTEVKA_SSL_CERTFILE` и `PUTEVKA_SSL_KEYFILE`.

| Файл или папка | Что это |
| --- | --- |
| `server.py` | Сервер (FastAPI): данные, вход и роли, расчёты, Word и Excel, документы, обновление. |
| `static/index.html` | Весь интерфейс программы. |
| `static/vendor/` | Библиотеки страницы (Tailwind, SheetJS, Chart.js, pdf.js), чтобы программа не зависела от внешних сайтов. |
| `static/ocr/` | Модели распознавания удостоверения (PaddleOCR). |
| `templates_xls/` | Бланк формы № 3. |
| `data/app_data.json` | Чистая стартовая база без людей и машин. |
| `desktop_app.py` | Оболочка для Windows; собирается в `Putevka.exe`. |
| `install.sh` | Установщик для Linux. |
| `update.ps1` | Ручное обновление на Windows, если кнопка не сработала. |
| `Dockerfile`, `docker-compose.yml` | Сборка своего образа Docker. |

**Выпуск.** Номер версии записан в `version.txt`, `server.py` и `static/index.html`. После отправки в `main` GitHub Actions проверяет код, собирает `Putevka.exe` и архивы и публикует выпуск. Сборка останавливается, если в стартовой базе или бланке оказались чьи-то данные. В репозиторий не попадают реальные ФИО, номера документов и пароли.

**Сторонние компоненты** и их лицензии перечислены в [static/vendor/NOTICE.txt](static/vendor/NOTICE.txt) и [static/ocr/NOTICE.txt](static/ocr/NOTICE.txt).

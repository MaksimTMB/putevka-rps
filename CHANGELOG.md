# История изменений (Changelog) — АСУ «ПУТЁВКА»

## [v8.0.0] — 2026-11-17
- **Новый интерфейс вместо «всего в одном окне».** Меню разделов слева: Обзор · Путевые листы · Чеки ГСМ · Документы · Профили и водители · Карты и адреса · Пользователи и доступ · Шапка путевого листа · Настройки приложения. На узком экране меню открывается кнопкой ☰.
- **Верхняя панель:** название раздела, выбор водителя (профиля) и периода — общие для всех разделов, версия программы (кликабельна, как раньше), пользователь и кнопка выхода. Старая карточка с данными водителя над каждым разделом убрана.
- **Новый раздел «Обзор»** (открывается после входа): автомобиль, госномер, водитель, организация и ответственные; показатели выбранного месяца (рабочие дни, заправлено, пробег, расход, остаток на начало и конец); быстрые действия (путевые листы, чек, ведомость, новый период, печать, Word, Excel, предпросмотр); список периодов и профилей — переход в один клик.
- **«Профили и водители» — отдельный раздел** (раньше был внизу «Пользователей и ролей»). «Пользователи и доступ» — только учётные записи.
- **«Путевые листы»:** короткие понятные кнопки, дни месяца и редактор дня сразу под параметрами месяца, график остатка — внизу.
- **«Чеки ГСМ»:** годы и месяцы — колонкой слева, начальный остаток, новый чек и таблица чеков — справа.
- **Фирменный стиль «Путёвки»:** логотип и значок программы, фирменные цвета, единые кнопки (главная — синяя, второстепенные — белые, удаление — красное), значки вместо эмодзи на кнопках, новые экраны входа и первичной настройки. Доработана тёмная тема.
- **Режим водителя** в том же оформлении: «Мои путевые листы», листы А4 больше не обрезаются по краям.
- Расчёты, печатная форма № 3 (ОКУД 0345001), выгрузка в Word/Excel и формат базы **не изменились** — все данные открываются как прежде.

## [v7.3.5] — 2026-11-16
- **Конец «полуобновлений» портативной (Windows) версии:** при обновлении из окна файлы на диске могли стать новыми, а сам exe — не замениться и не перезапуститься. Программа застревала «наполовину обновлённой»: жёлтая плашка «страница/сервер не совпадают», F5 не помогает (жалоба владельца после v7.3.4). Теперь:
  - **страница всегда берётся из комплекта самого exe** — версии страницы и сервера совпадают «по построению», рассогласование невозможно в принципе;
  - **новый exe скачивается первым** (до 3 попыток, с проверкой размера); не скачался — обновление не начинается вовсе, программа спокойно работает прежней версией и честно сообщает об этом;
  - **жёлтая плашка понимает направление рассогласования:** если программа старее страницы — пишет «F5 не поможет: закройте окно, завершите Putevka.exe в диспетчере задач, запустите с ярлыка или update.ps1» (клик по плашке показывает пошаговую подсказку);
  - окно ожидания перезапуска через 3 минуты советует update.ps1, если версия не поменялась.

## [v7.3.4] — 2026-11-16
- **Можно удалить все шаблоны шапки, включая последний:** раньше программа не давала удалить единственный оставшийся шаблон, называя его «базовым» («В системе должен оставаться хотя бы один базовый шаблон шапки»). Никаких «базовых» шаблонов в коде нет — все шаблоны создаёт пользователь, и пустой список теперь штатное состояние (селекторы показывают «Нет сохраненных шаблонов»). Сама форма путевого листа (ОКУД 0345001) никуда не девается.
- **Бейдж версии кликабелен всегда:** зелёный («актуальная версия») тоже — нажатие проверяет обновления ещё раз и при желании принудительно переустанавливает файлы программы из GitHub. Причина: старые версии при сбойной проверке молча показывали зелёный бейдж, и из окна обновиться было невозможно — только скриптом update.ps1 (жалоба владельца: «не было жёлтого бейджа, обновился только через пс»).
- **Серый бейдж «проверка недоступна»** при нажатии запускает проверку и предлагает принудительное обновление (раньше клик лишь тихо перепроверял).
- **Третий источник проверки версии** (`raw.githubusercontent.com/.../version.txt`) — обновление видно, даже когда недоступны API и сам сайт GitHub (проверка: API → переход releases/latest → raw version.txt).

## [v7.3.3] — 2026-11-16
- **Можно удалить последний месяц:** раньше программа не давала удалить единственный оставшийся расчётный период профиля — «последний загруженный месяц не удаляется». Теперь любой месяц удаляется полностью (со маршрутами и чеками); профиль без месяцев — нормальное состояние, в каждом окне подсказка, как создать месяц заново («+ Добавить новый период» или загрузка ведомости).
- **Жёлтый баннер «Страница устарела»:** если открытая в браузере страница старее сервера (старая вкладка, кэш) — при старте появляется жёлтая полоса с обеими версиями и подсказкой нажать F5. Клик по баннеру обновляет страницу. Защита от «вернувшихся» старых багов после обновления: раньше бейдж показывал версию сервера и всё выглядело правильным, а в браузере работала старая логика.
- **Исправлено:** в шапке на долю секунды до загрузки мелькала старая версия v7.2.3.
- **Режим водителя:** устранена потенциальная ошибка интерфейса у профиля без месяцев (пустой список периодов).

## [v7.3.2] — 2026-11-15
- **Честная и надёжная проверка обновлений:** версия ищется двумя способами — официальное API GitHub и безлимитный переход по ссылке «последний релиз» (конечный адрес содержит номер версии) — с кэшем на 10 минут. Раньше единственный запрос к API мог не пройти (нет связи, лимит 60 запросов в час) — и программа молча показывала «у вас актуальная версия», скрывая доступное обновление.
- **Серый бейдж вместо обмана:** если проверить обновление не удалось, бейдж версии показывает «проверка недоступна» — клик по нему повторяет проверку. Зелёным «актуальная версия» бейдж становится только когда проверка реально выполнена и новой версии нет.
- **Ручное обновление всегда под рукой:** если обновление не видно, запустите `update.ps1` (правый клик → «Выполнить с помощью PowerShell») — он принудительно скачает последнюю версию, сохранит базу и пересоздаст ярлыки.

## [v7.3.1] — 2026-11-15
- **Надёжное обновление серверной версии по кнопке:** все файлы сначала скачиваются с повторными попытками (до 3 раз на файл, таймаут 60 с), и только после полного успеха применяются разом — «полуобновлений» (сервер новый, страница старая) больше не будет. Если какой-то файл не скачался, программа честно пишет какой — и продолжает работать прежней версией без изменений.
- **Сервер перезапускается через 4 секунды после обновления** (было 1.2 с): ответ и сообщение об успехе успевают дойти до браузера — ошибка «Failed to fetch» при обновлении больше не появляется. Если сеть всё же оборвалась, подсказка предлагает обновить страницу (F5) через несколько секунд.
- **Окно ожидания перезапуска ждёт именно новую версию** (сверяет ответ сервера), а не первый отклик — страница не перезагрузится на старую версию.
- **Исправлен заголовок вкладки браузера:** в нём оставалась версия v7.2.3 (шапка окна показывала старую версию при верном бейдже).
- Версии во всех скриптах обновления (update.sh, update_on_server.sh, setup_and_run.sh, update.ps1) приведены в порядок.

## [v7.3.0] — 2026-11-15
- **Заправочные выезды выходных дней:** чек АЗС, пришедшийся на субботу или воскресенье, больше не переносится на чужой рабочий день. Для него создаётся отдельный день-выезд «база → АЗС → база» со своим путевым листом: прибытие на АЗС ровно по времени чека, реальная пауза на заправку (5–14 минут), реальный километраж и время в пути. Выезд виден в списке дней с жёлтой меткой «⛽ заправочный выезд», участвует в топливном балансе (своя графа расхода/заправки в цепочке бака) и печатается/экспортируется как обычный ПЛ.
- **Нестандартные чеки — время читается правильно:** в парсере ведомостей колонка «Время» теперь главный источник времени чека (раньше программа могла взять время, «зашитое» в ячейку даты, и чек оказывался не в то время дня). Поддержаны нестандартные форматы: 8.42, 8,42, 8-42, 8ч42м, 8 ч 42 мин, 0842, время дробью Excel.
- **Несколько чеков за один день:** маршрут дня строится по самому раннему времени чека (раньше могло «победить» время последней строки ведомости).
- **Удаление чека выходного дня удаляет и сам выезд** (с понятным подтверждением), правка времени/АЗС в ведомости чеков пересобирает выезд под новое время.
- **В таблице маршрутов** у плеча ⛽ теперь показано время чека: «⛽ заезд на заправку по чеку (8:42)».

## [v7.2.3] — 2026-11-15
- **Заправка до/после смены по времени чека:** ранний чек (до 9:00) — АЗС первый маршрут дня (база → АЗС → работа), поздний чек (после 18:00) — последний (работа → АЗС → база), чек внутри смены — АЗС в середине (работа → АЗС → работа).
- **Реальное время в пути:** убрано «сжатие» переездов до 4 минут; ранняя заправка просто начинается раньше (выезд = чек − время в пути), поздняя заканчивается позже (возврат = чек + заправка + путь). Скорость остаётся реалистичной (30–40 км/ч).
- **Шапка ПЛ:** в графы «Выезд» и «Возврат» подставляются фактические времена первого и последнего плеча маршрута дня (в предпросмотре, печати и экспорте Word/Excel); подписи в интерфейсе тоже показывают реальное время.
- **Бейдж версии в шапке:** стал кнопкой — зелёный, если версия актуальна, жёлтый, если есть обновление (клик по жёлтому запускает обновление). Отдельная кнопка «Обновить» убрана.
- **Портативная версия:** установщик создаёт настоящий ярлык «ПУТЁВКА.lnk» на Рабочем столе и в меню «Пуск» (с иконкой программы) вместо копии exe; повторный запуск обновляет ярлык, а не создаёт второй.

## [v7.2.2] — 2026-11-15
- **Исправлена логика маршрутов в дни с чеком АЗС:** день теперь всегда начинается в 9:00 и заканчивается в 18:00, а заправка стоит строго в середине дня (работа → АЗС → работа) и прибывает ровно по времени чека. Раньше такой день мог схлопнуться в «база → АЗС → база»: выезд сдвигался ко времени чека, а обратное плечо растягивалось до 18:00 (нереально долго на короткий километраж).
- **Старые испорченные дни чинятся сами:** автоперестройка при запуске теперь пересобирает и дни, где АЗС стоит первой/последней строкой или в маршруте меньше 4 плеч (не только дни совсем без заезда на АЗС).


## [v7.2.1] — 2026-11-15
- **Заправка в маршрутах появляется сразу после обновления:** при запуске программы месяцы, где есть чеки АЗС, но маршруты ещё без заезда на заправку (старые данные), автоматически перестраиваются — вручную ничего пересчитывать не нужно.
- **Исправлено обновление Windows-версии по кнопке:** после обновления окно программы больше не показывает «127.0.0.1 отказано в подключении» — вместо перезагрузки в мёртвый сервер окно показывает статус «Ждём перезапуск программы…» и само обновляется, когда новая версия поднялась.
- **Стабильный порт Windows-версии:** новый exe после обновления запускается на том же порту, что и старый (порт запоминается в файле); повторный запуск программы не плодит вторые копии — просто открывается окно к уже работающей.
- **Надёжная замена exe:** если файл не удалось заменить (занят другим процессом), программа всё равно запустится — прежней версией; все шаги замены пишутся в журнал `update.log` рядом с exe.
- Пауза перед остановкой старой версии увеличена, чтобы сообщение об обновлении успело дойти до окна.

## [v7.2.0] — 2026-11-15
- **Заправка встроена в маршрут дня:** в день с чеком АЗС генератор теперь прокладывает маршрут через саму заправку — плечо «объект → АЗС» и выезд с АЗС дальше по маршруту. Прибытие на АЗС совпадает со временем чека; при необходимости смена дня подстраивается (выезд раньше / возврат позже, в разумных пределах 7:00–20:30). На самой АЗС — короткая пауза на заправку (5–14 минут). Плечо с АЗС помечено значком ⛽ в таблице маршрутов и попадает в предпросмотр, печать и экспорт Word/Excel.
- **Исправлено удаление чеков ГСМ:** изменения теперь сохраняются на сервер ДО перерисовки экрана, а перерисовка защищена от ошибок — удаление чека (включая последний в месяце) больше не может «откатиться» после перезагрузки страницы.
- **Удаление чека обнулением:** в окне «Чеки ГСМ» теперь достаточно ввести 0 в поле литров и нажать «Сохранить» — чек будет удалён (с сообщением).
- **Починен ввод номера чека:** в таблице чеков поле «№ чека» больше не вызывает ошибку при вводе.
- **Удаление документов (Окно 6):** та же защита — сначала сохранение, потом обновление списка.

## [v7.1.4] — 2026-11-14

## [v7.1.3] — 2026-11-14

- **Хеширование паролей:** пароли пользователей хранятся в зашифрованном виде (SHA-256); вход работает со старыми и новыми паролями, пароль больше не отображается в таблице пользователей.

## [v7.1.0] — 2026-11-13
- **Браузер документов и хранилище файлов:** новое Окно 6 «Документы» — загруженные ведомости, сгенерированные и распечатанные путевые листы сохраняются на диск (`data/documents/`) с карточкой (тип, водитель, месяц, дата) и доступны для скачивания, повторного открытия в нужном окне и удаления.
- **Умный приёмник файлов:** при загрузке таблицы программа сама определяет её тип — если это ведомость чеков ГСМ, применяет к чекам; если другая ведомость — сохраняет как документ водителя.
- **Автосохранение документов:** экспорт путевого листа в Word/Excel автоматически сохраняет копию в хранилище.
- **Обновление из интерфейса для обеих версий:** веб-версия перезапускает сервер после обновления, Windows-версия скачивает новый exe и заменяет себя автоматически.

## [v7.0.5] — 2026-11-13

- **Показ вместо редактирования:** в Окне 1 «Настройка шапки» и в Окне 2 «Генератор» нормы теперь только отображаются (значение берётся из профиля); ручные «Базовая норма» и «Отклонение нормы» удалены.
- **Убрано поле «Межсезонье»** (остались только Лето и Зима); шаблоны шапки больше не хранят нормы расхода.

## [v7.0.4] — 2026-11-09
